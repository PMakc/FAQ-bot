# FAQ Бот Горной академии ЗабГУ для платформы MAX

Этот бот предоставляет интерактивный справочник с часто задаваемыми вопросами для студентов и абитуриентов Горной академии Забайкальского государственного университета (ЗабГУ). Бот работает в мессенджере **MAX** и позволяет получить быстрый доступ к информации о факультетах, расписании, общежитии, стипендиях, документах и других важных аспектах учебной жизни.

---

## 📌 Возможности

- Разделы:
  - 🏛️ Факультеты (Горный, Энергетический, ФКНИТ)
  - 📚 Учёба (процесс, пропуски, экзамены, деканат)
  - 📅 Расписание (где смотреть, аудитории, изменения)
  - 🏠 Общежитие (заселение, документы, правила)
  - 💰 Стипендия (виды, размеры)
  - 📄 Документы (студенческий, зачётка, справки)
  - ⛏️ Практика (прохождение, документы)
  - 📖 Библиотека (литература, электронные ресурсы)
  - 📲 Канал в MAX (ссылка для подписки)
  - 📞 Контакты (сайт, факультеты, студенческий офис)

- Навигация с помощью интерактивных кнопок (callback-клавиатура).
- Ответы на вопросы при нажатии на соответствующую кнопку.
- Возврат в главное меню или в раздел.

## 🚀 Установка и запуск

### Требования

- Python 3.6 или выше.
- Установленная библиотека `requests` (версия 2.x).

### Шаги

1. Клонируйте репозиторий или скачайте файл `FAQ.py`.
2. Установите зависимость:

   ```bash
   pip install requests
   ```

3. Создайте файл `bot_token.txt` в той же директории, что и скрипт, и поместите в него токен бота для платформы MAX (текст без лишних пробелов и переводов строк).

4. Запустите бота:

   ```bash
   python FAQ.py
   ```

После запуска бот начнёт получать обновления через Long Polling API MAX и будет отвечать на команды пользователей.

## 🔧 Настройка

- **Токен бота** – хранится в файле `bot_token.txt`. Бот читает его при старте.
- **Базовый URL** – в коде прописан `https://platform-api2.max.ru`. При необходимости его можно изменить.
- **SSL** – проверка сертификатов отключена (`session.verify = False`) для совместимости с тестовой средой MAX. В продакшене рекомендуется включить проверку.

## ✏️ Добавление новых вопросов

Все вопросы и ответы хранятся в словаре `FAQ` в файле `FAQ.py`. Он организован по разделам (`faculties`, `study`, `schedule` и т.д.). Чтобы добавить новый вопрос:

1. Откройте файл `FAQ.py`.
2. Найдите нужный раздел или создайте новый.
3. Внутри словаря `questions` добавьте новый ключ (уникальный идентификатор), например:

   ```python
   "my_new_question": {
       "title": "❓ Мой новый вопрос",
       "answer": "Здесь текст ответа..."
   }
   ```

4. Сохраните файл и перезапустите бота. Новая кнопка автоматически появится в меню раздела.

## 📝 Примечания

- Бот использует механизм **Long Polling** для получения событий от платформы MAX.
- Все логи выводятся в консоль с уровнем `INFO`. Для отладки можно установить `logging.DEBUG`.
- При обработке событий бот проверяет тип обновления (`bot_started`, `message_created`, `message_callback`) и вызывает соответствующие обработчики.
